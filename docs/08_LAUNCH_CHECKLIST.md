# Pilot Launch Checklist

## Product

- [ ] At least 5 live bounties
- [ ] Every bounty has objective hard criteria
- [ ] Reward is clearly visible
- [ ] Existing CRM rule defined
- [ ] No-show rule defined
- [ ] Meeting definition defined
- [ ] Quota and expiry defined

## Operations

- [ ] One admin owns moderation
- [ ] Dispute SLA defined
- [ ] Manual payout procedure documented
- [ ] Fraud escalation procedure documented
- [ ] Support Telegram/email exists
- [ ] Daily reconciliation ritual exists

## Trust

- [ ] Business identities verified
- [ ] SDR email verified
- [ ] Bounty funding visible
- [ ] Stats visible
- [ ] Criteria cannot change retroactively
- [ ] Event history available to admin

## Legal / money

- [ ] Legal counsel reviewed platform model
- [ ] Terms specify platform role
- [ ] Performer/customer relationship characterized
- [ ] Tax/receipt obligations mapped
- [ ] Personal-data flow mapped
- [ ] Consent/legal basis for prospect data mapped
- [ ] Outreach/channel compliance mapped
- [ ] Payment provider approved the exact marketplace flow
- [ ] Do not describe internal ledger as escrow

## Pilot metrics collected weekly

- funded bounty GMV
- active bounties
- SDRs who took bounty
- SDRs who submitted prospect
- accepted meetings
- median time to first accepted meeting
- acceptance rate
- dispute rate
- no-show rate
- advertiser repeat rate
- payout time
